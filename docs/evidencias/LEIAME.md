# Convenção de evidências

- O nome de cada arquivo começa pelo identificador do cenário, por exemplo `CT-FRETE-02.png`.
- Capturas de tela devem ser salvas no formato PNG.
- Respostas de API devem ser salvas no formato JSON, incluindo cenário, endpoint, método, corpo enviado, status e resposta recebida.
- Quando um cenário exigir mais de uma captura ou resposta, acrescente os sufixos `-1`, `-2` e assim por diante antes da extensão.
- As pastas `api`, `interface` e `manual` separam evidências por origem. Cenários manuais ainda não executados não possuem evidências.
